## 2. Investigation Summary

- Direct GET to Cleartrip search URL returns a Next.js application shell.
- The embedded `__NEXT_DATA__` script tag contains `initialState` with `results: {"data": {}, "isLoading": true}`, indicating flight results are fetched client-side via asynchronous requests.
- Asynchronous API endpoints require Akamai telemetry tokens generated by client-side browser execution.
- In strict adherence to project ethical guidelines (no stealth bypass), Cleartrip is classified as `SOURCE_BLOCKED`.
- The parser (`CleartripSource.parse_html` and `CleartripSource.parse_json`) is implemented and tested to parse `__NEXT_DATA__` JSON or HTML card structures.
